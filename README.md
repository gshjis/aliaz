# Aliaz

Бэкенд-сервис для изучения иностранных слов. Реализует регистрацию, авторизацию и аутентификацию пользователей, а также запись слов. Запись слов основана на внешних сервисах-переводчиках, поэтому на текущем этапе перевод реализован в виде **заглушки** (stub), которую в дальнейшем можно заменить на реального провайдера.

Проект построен на **FastAPI** и организован как **монорепозиторий из нескольких Poetry-пакетов**.

---

## Требования (Requirements)

### Функциональные

- **Регистрация** — создание нового пользователя по `nickname`, `email` и `password` (пароль хранится только в виде хэша).
- **Авторизация** — вход по `email` + `password`, выдача JWT-токена доступа.
- **Аутентификация** — проверка JWT-токена для защищённых эндпоинтов (получение текущего пользователя, работа со словами).
- **Запись слов** — пользователь добавляет слово, сервис получает перевод через внешний сервис-переводчик (сейчас — заглушка) и сохраняет слово вместе с переводом.
- **Управление словами** — просмотр списка своих слов, получение одного слова, удаление слова. Каждый пользователь видит и редактирует только свои слова.

### Нефункциональные

- **Асинхронность** — весь стек (FastAPI + SQLAlchemy async + asyncpg/aiosqlite) асинхронный.
- **Модульность** — логика разбита на независимые Poetry-пакеты с чёткими границами ответственности.
- **Безопасность** — пароли не хранятся в открытом виде; токены подписываются секретом из конфигурации.
- **Расширяемость** — сервис переводчика реализован через абстракцию, что позволяет подключать реальные API без изменения бизнес-логики.

### Слои

1. **API-слой** (`src/aliaz`) — FastAPI-приложение: роутеры, Pydantic-схемы запросов/ответов, DI-зависимости.
2. **Сервисный слой** (`packages/auth`, `packages/translator`) — бизнес-логика: безопасность, токены, перевод.
3. **Слой данных** (`packages/database`) — ORM-модели, асинхронные сессии, инициализация БД.
4. **Конфигурация** (`packages/config`) — настройки из переменных окружения / `.env`.

## Пакеты (Poetry)

Проект — монорепозиторий. Каждый пакет — самостоятельный Poetry-пакет, подключаемый в корневой `pyproject.toml` через `file://` (в dev-режиме — `develop = true`).

| Пакет | Назначение | Зависимости |
|-------|-----------|-------------|
| `config` | Глобальные настройки (БД, JWT, сервер) | `pydantic-settings` |
| `database` | ORM-модели, асинхронное подключение, инициализация БД | `sqlalchemy[asyncio]`, `asyncpg`, `aiosqlite`, `config` |
| `auth` | Хэширование паролей, выпуск/проверка JWT, DI-зависимость текущего пользователя | `bcrypt`, `pyjwt`, `config`, `database` |
| `translator` | Абстракция сервиса перевода + заглушка | — |
| `aliaz` (корневой) | FastAPI-приложение, роутеры, схемы | `fastapi`, `uvicorn`, все пакеты выше |

## Бэкенд-логика

### Регистрация

`POST /auth/register`

1. Принимает `nickname`, `email`, `password` (и опционально `telegram_nickname`).
2. Проверяет уникальность `email` и `nickname`; при конфликте возвращает `409 Conflict`.
3. Хэширует пароль (`bcrypt`) и сохраняет пользователя.
4. Выпускает JWT-токен и возвращает его вместе с данными пользователя.

### Авторизация

`POST /auth/login`

1. Принимает `email` и `password`.
2. Ищет пользователя по `email`; проверяет пароль через `bcrypt`.
3. При успехе выпускает JWT-токен; при неверных данных — `401 Unauthorized`.

### Аутентификация

- Защищённые эндпоинты требуют заголовок `Authorization: Bearer <token>`.
- DI-зависимость `get_current_user` декодирует JWT, извлекает `user_id` и загружает пользователя из БД.
- При отсутствии/невалидности/просрочке токена — `401 Unauthorized`.

### Запись слов

`POST /words`

1. Принимает слово (`word_en`).
2. Вызывает сервис-переводчик для получения перевода (сейчас — `StubTranslator`).
3. Сохраняет слово и перевод, привязывая к текущему пользователю.

`GET /words` — список слов текущего пользователя.
`GET /words/{id}` — одно слово (только своё).
`DELETE /words/{id}` — удаление (только своё).

## API (сводка)

| Метод | Путь | Аутентификация | Описание |
|-------|------|----------------|----------|
| POST | `/auth/register` | нет | Регистрация |
| POST | `/auth/login` | нет | Авторизация |
| GET | `/auth/me` | да | Текущий пользователь |
| POST | `/words` | да | Добавить слово (с переводом) |
| GET | `/words` | да | Список своих слов |
| GET | `/words/{id}` | да | Одно слово |
| DELETE | `/words/{id}` | да | Удалить слово |

Интерактивная документация: `http://localhost:8000/docs` (Swagger UI).

## Веб‑интерфейс
Для взаимодействия с сервисом удобно иметь простое веб‑приложение, которое
показывает список слов пользователя, позволяет добавлять новые слова и
просматривать/удалять существующие. В качестве основы можно использовать
статический HTML/JavaScript, но более гибким решением будет SPA на
React/Vue/Angular, подключённый к API через `fetch`/`axios`.

### Минимальные требования
* **Авторизация** – пользователь должен войти через `/auth/login` и получить
  JWT‑токен, который хранится в `localStorage`/`sessionStorage`.
* **Получение списка слов** – GET‑запрос к `/words` с заголовком
  `Authorization: Bearer <token>`.
* **Добавление слова** – POST‑запрос к `/words` с полем `word_en`.
* **Удаление слова** – DELETE‑запрос к `/words/{id}`.
* **Показ текущего пользователя** – GET‑запрос к `/auth/me`.

### UI‑компоненты
* **Login / Register** – формы с полями `email`, `password`, `nickname`.
* **Word list** – таблица/карточки со словами и переводами.
* **Add word** – простая форма ввода нового слова.
* **Logout** – кнопка, которая очищает токен и перенаправляет на страницу
  входа.

### Технологии
* **Frontend** – React (Create‑React‑App) или Vue CLI, но можно и Vanilla
  JS.
* **HTTP клиент** – `fetch` или `axios`.
* **Стили** – Tailwind CSS или Bootstrap.
* **Хранение токена** – `localStorage` (с учётом XSS‑рисков) или
  `httpOnly` cookie, если сервер поддерживает CORS‑cookie.

Если планируется развертывание в продакшене, стоит добавить
`https://`‑подключение, CORS‑политику и защиту от CSRF.

## Модели данных

**User** (`users`)

| Поле | Тип | Примечание |
|------|-----|-----------|
| `id` | int | PK |
| `nickname` | str | уникальный |
| `email` | str | уникальный |
| `password_hash` | str | bcrypt-хэш |
| `telegram_nickname` | str? | опционально |

**Word** (`words`)

| Поле | Тип | Примечание |
|------|-----|-----------|
| `id` | int | PK |
| `owner_id` | int | FK → `users.id` |
| `word_en` | str | исходное слово |
| `translation` | str? | перевод от сервиса |
| `created_at` | datetime | время создания |

## Запуск

```bash
# Установка зависимостей (корневой пакет + все подпакеты)
poetry install

# Настройка окружения
cp .env.example .env

# Инициализация базы данных
poetry run python -m aliaz.init_db

# Запуск сервера
poetry run uvicorn aliaz.main:app --reload
```
